# FitStart AI

เว็บเริ่มต้นออกกำลังกายด้วย AI (ไทย / อังกฤษ)
เปิดใช้งาน: ดับเบิลคลิก `index.html`

## โครงสร้างไฟล์

```
SFProject/
├── index.html        หน้าแรก (โครงหน้าเว็บ HTML)
├── css/
│   └── style.css     หน้าตา สี ขนาด การจัดวาง
└── js/
    ├── i18n.js       ข้อความทั้งหมดภาษาไทย/อังกฤษ  ← แก้คำในเว็บที่นี่
    ├── data.js       คลังท่าออกกำลังกาย          ← เพิ่ม/แก้ท่าที่นี่
    ├── utils.js      ตัวช่วยทั่วไป (ใช้ร่วมกันทุกไฟล์)
    ├── planner.js    ระบบสร้างแผนออกกำลังกาย
    ├── tools.js      คำนวณ BMI และตัวจับเวลาพัก
    ├── auth.js       ระบบสมาชิก (แบบจำลอง) และแผนที่บันทึกไว้
    └── main.js       เริ่มต้นแอป และสลับภาษา
```

## ข้อควรรู้

- ไฟล์ใน `js/` ต้องโหลดตามลำดับที่เขียนไว้ท้าย `index.html` เพราะไฟล์หลังๆ ใช้ของจากไฟล์ก่อนหน้า
- ระบบสมาชิกเป็น **แบบจำลอง**: ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ห้ามใช้รหัสผ่านจริง
