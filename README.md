# FitStart AI

เว็บเริ่มต้นออกกำลังกายด้วย AI (ไทย / อังกฤษ)
เปิดใช้งาน: ดับเบิลคลิก `index.html` · ออนไลน์: https://gpt672191-dotcom.github.io/FSdemo/

## หน้าเว็บ

| ไฟล์ | หน้า | มีอะไร |
|---|---|---|
| `index.html` | หน้าแรก | แนะนำเว็บ และการ์ดเลือกหมวด |
| `for-you.html` | แนะนำ | คำแนะนำจาก น้ำหนัก/ส่วนสูง/อายุ: เป้าหมาย, แคลอรี่, โปรตีน, แผน, ท่า |
| `profile.html` | ข้อมูลส่วนตัว | ดู/แก้ไขข้อมูลสมาชิก (เมนูมุมขวาบน) |
| `muscle.html` | สร้างกล้าม | เลือกกล้ามเนื้อ 7 ส่วน (อก หลัง ไหล่ แขน ขา ก้น หน้าท้อง), หลักการ, คำนวณโปรตีน |
| `weight-loss.html` | ลดน้ำหนัก | หลักการ, คำนวณแคลอรี่, ท่าเผาผลาญ |
| `planner.html` | สร้างแผน | ให้ AI จัดตาราง, บันทึกแผน, แผนของฉัน |
| `bmi.html` | คำนวณ BMI | BMI, น้ำหนักที่เหมาะสม, ตารางเกณฑ์ |
| `more.html` | อื่นๆ | ตัวจับเวลาพัก, เคล็ดลับ, คำถามที่พบบ่อย |

## โครงสร้างไฟล์

```
SFProject/
├── *.html             หน้าเว็บทั้ง 6 หน้า (ด้านบน)
├── css/
│   └── style.css      หน้าตา สี ขนาด การจัดวาง
└── js/
    ├── i18n.js        ข้อความทั้งหมดภาษาไทย/อังกฤษ   ← แก้คำในเว็บที่นี่
    ├── data.js        คลังท่าออกกำลังกาย           ← เพิ่ม/แก้ท่าที่นี่
    ├── utils.js       ตัวช่วยที่ใช้ร่วมกันทุกหน้า
    ├── figures.js     ตัวละครแอนิเมชั่น 2D ทุกท่า  ← เพิ่ม/แก้ท่าใน MOTIONS
    ├── bodymap.js     ภาพร่างกายหน้า/หลัง ไฮไลต์กล้ามเนื้อ
    ├── muscle-groups.js หน้าสร้างกล้าม แยกตามกล้ามเนื้อ (muscle.html#chest ฯลฯ)
    ├── icons.js       ไอคอนเล็กบนปุ่ม
    ├── layout.js      เมนูด้านบน หน้าต่างเข้าสู่ระบบ ส่วนท้าย  ← เพิ่มเมนูที่นี่
    ├── auth.js        ระบบสมาชิก (แบบจำลอง)
    ├── for-you.js     กฎการแนะนำ ปรับได้ที่ recommend()  (for-you.html)
    ├── profile.js     ข้อมูลส่วนตัว               (profile.html)
    ├── planner.js     สร้างแผน + แผนของฉัน      (planner.html)
    ├── exercises.js   รายการท่าแบบกรองได้        (muscle, weight-loss)
    ├── calculators.js คำนวณโปรตีน / แคลอรี่      (muscle, weight-loss)
    ├── bmi.js         คำนวณ BMI                (bmi.html)
    ├── timer.js       ตัวจับเวลาพัก              (more.html)
    └── main.js        เริ่มต้นหน้าเว็บ (โหลดเป็นไฟล์สุดท้ายเสมอ)
```

## ข้อควรรู้

- ทุกหน้าโหลด `i18n → data → utils → icons → figures → layout → auth → (ไฟล์ของหน้านั้น) → main` ตามลำดับนี้
- เมนูและส่วนท้ายเขียนไว้ที่เดียวใน `layout.js` แก้ทีเดียวเปลี่ยนทุกหน้า
- ลิงก์ `planner.html?goal=muscle` หรือ `?goal=lose` จะเลือกเป้าหมายไว้ให้อัตโนมัติ
- ระบบสมาชิกเป็น **แบบจำลอง**: ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ห้ามใช้รหัสผ่านจริง
